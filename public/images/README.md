# Public Images

Store static images here.

## Usage
Images placed in this folder can be accessed directly via URL.

**Example:**
If you place `profile.jpg` here:
```html
<img src="/images/profile.jpg" alt="Profile" />
```

**Recommended for:**
- Favicons
- Robots.txt
- Images referenced dynamically by string path in your code
- Open Graph images (for social media previews)
